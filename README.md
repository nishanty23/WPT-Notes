# WPT Notes — Web Programming Technologies

A structured collection of notes on **Web Programming Technologies (WPT)**, organized day by day for learning, revision, and practical understanding.

This repository covers the fundamentals of web development and gradually builds toward advanced concepts used in real-world software development.

## 📚 Repository Structure

```text
WPT-Notes/
│
├── README.md
│
├── day1/
│   ├── web-application.md
│   └── advanced/
│       └── advanced-topics.md
│
├── day2/
│   └── topic-name.md
│
└── day3/
    └── topic-name.md
```

> The structure is flexible. Each day can contain one or more Markdown files based on the topics covered.

## 🗓️ Daily Notes

The notes are organized by study day to make learning systematic and easy to follow.

- **Day 1:** Introduction to web applications, client-server architecture, HTTP requests and responses, and HTML basics.
- **Day 2 onwards:** Topics will be added progressively as the course advances.

Each daily folder contains explanations, syntax, code examples, and relevant concepts covered during learning.

## 🚀 Advanced Topics

The `advanced/` directory inside a day's folder is dedicated to concepts that go beyond introductory notes.

For example:

```text
day1/
├── web-application.md
└── advanced/
    └── advanced-topics.md
```

Advanced notes aim to explain concepts at two levels:

1. **Simple Explanation:** Understand the concept intuitively, using relatable examples and step-by-step explanations.
2. **Industry-Level Explanation:** Understand how the concept works technically in real-world applications, including architecture, implementation details, best practices, limitations, and practical use cases where relevant.

The goal is to connect classroom fundamentals with how web technologies are used in production systems.

## 🎯 Learning Objectives

- Understand the fundamentals of web programming.
- Learn HTML, CSS, JavaScript, and related technologies.
- Understand client-server communication and web application architecture.
- Practice concepts through code examples.
- Explore advanced topics with both beginner-friendly and technically detailed explanations.
- Build a structured reference for revision, interviews, and practical development.

## 📝 Notes Format

All notes are written in **Markdown (`.md`)** for readability and easy navigation.

The notes may include:

- Headings and subheadings
- Syntax and code snippets
- Tables and lists
- Practical examples
- Technical explanations
- Links to useful references

They can be viewed directly on GitHub or locally using a Markdown editor such as Visual Studio Code.

## 📌 How to Use This Repository

1. Start with `day1/` and continue in chronological order.
2. Read the regular notes to understand the fundamentals.
3. Explore the corresponding `advanced/` directory for deeper technical understanding.
4. Run and experiment with the code examples wherever applicable.
5. Use the notes for revision and refer back to advanced explanations when needed.
